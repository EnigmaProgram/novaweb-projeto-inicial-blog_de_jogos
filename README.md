# Projeto NovaWeb Studio – Blog de Jogos

## Descrição do Projeto

O projeto consiste na criação de um blog voltado ao público gamer, oferecendo conteúdos como análises de jogos, novidades, dicas e tendências do mercado de games.

O site apresentará uma navegação simples e responsiva, permitindo que qualquer pessoa interessada encontre facilmente informações sobre jogos e notícias do universo gamer.

## Requisitos do Sistema

- Windows, Linux ou macOS
- Git instalado
- VS Code

## Informações do Projeto

- Tema: Blog de Jogos
- Tipo: Blog Temático
- Público-Alvo: Público Gamer Geral

## Requisitos Funcionais

### RF01 – Navegação
O sistema deve possuir um menu de navegação presente em todas as páginas principais.

### RF02 – Página Inicial
O sistema deve apresentar uma página inicial com informações sobre o blog e conteúdos em destaque.

### RF03 – Página de Postagens
O sistema deve disponibilizar uma página contendo postagens ou análises de jogos organizadas em cards.

### RF04 – Visualização de Conteúdo
O usuário deve conseguir acessar e visualizar as informações das postagens por meio dos links disponibilizados.

### RF05 – Página de Contato
O sistema deve possuir uma página de contato contendo um formulário para comunicação com o responsável pelo blog.

### RF06 – Navegação entre Páginas
As páginas do site devem estar interligadas, permitindo a navegação entre Home, Postagens e Contato.

## Requisitos Não Funcionais

### RNF01 – Responsividade
O site deverá adaptar sua interface a diferentes tamanhos de tela, como computadores, tablets e smartphones.

### RNF02 – Organização do Projeto
Os arquivos HTML, CSS, JavaScript (se houver) e imagens deverão estar organizados em diretórios específicos.

### RNF03 – Usabilidade
A navegação deverá ser simples, intuitiva e de fácil compreensão para o usuário.

### RNF04 – Padronização
O projeto deverá seguir um padrão de nomenclatura para arquivos, pastas e estrutura do código.

### RNF05 – Desempenho
As páginas deverão carregar rapidamente e utilizar imagens otimizadas sempre que possível.

### RNF06 – Compatibilidade
O site deverá funcionar corretamente nos principais navegadores modernos, como Google Chrome, Microsoft Edge e Mozilla Firefox.
